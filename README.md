# 🔎 Hidden Jobs — מוצא משרות נסתרות

מערכת שמוצאת משרות שמתפרסמות **רק באתרי הבית של החברות** ולא בלוחות דרושים (AllJobs, Drushim, LinkedIn…).

## איך זה עובד — אנלוגיה

תחשבי על זה כמו לחפש דירה בלי יד2: מסתובבים ברחובות (גוגל מפות), רושמים כל בניין (כל עסק עם אתר),
בודקים באיזה בניין תלוי שלט "להשכרה" (עמוד דרושים), ונכנסים רק לאלה כדי לבדוק אם יש דירה שמתאימה לך (התפקיד).

| שלב | מה קורה | איך |
|---|---|---|
| **1. איסוף מקומות** | רק סוגי מקומות שרלוונטיים לתפקיד (SOC → חברות סייבר, IT, תקשורת, בנקים…) | Google Places API, עם **פיצול אדפטיבי של המפה** (Quadtree), וסינון חנויות/מסעדות/בילוי לפי סוג המקום בגוגל |
| **1ב. Dorking (במקביל)** | שאילתות גוגל מתקדמות | `site:comeet.com "SOC" "פתח תקווה"`, `inurl:careers ...`, `intitle:דרושים ...` — עם החרגה של לוחות הדרושים |
| **2. איתור עמוד קריירה** | מצמצם לאתרים שיש להם דרושים | סורק את דף הבית לקישורים כמו "דרושים / קריירה / Careers / Join us", ואם אין — בודק נתיבים נפוצים (`/careers`, `/jobs`, `/דרושים`…) |
| **3. חיפוש התפקיד** | מוצא את המשרות עצמן + קישור ישיר | אם החברה משתמשת במערכת גיוס (Comeet, Greenhouse, Lever, Ashby, Workable, SmartRecruiters, BambooHR, Breezy, Recruitee) — מושך את כל המשרות מה-JSON הציבורי שלה. אחרת — מנתח את ה-HTML, עוקב אחרי "לכל המשרות"/עמודים נוספים |

### למה Quadtree?
גוגל מחזיר **מקסימום 60 תוצאות** לשאילתה. בפתח תקווה יש מאות חברות "משרדים", אז שאילתה אחת מפספסת רוב.
המערכת מחפשת על כל העיר; אם חזרו ~60 (= "רווי") היא חותכת את האזור ל-4 ומחפשת בכל רבע, וכך הלאה.
אזור צפוף כמו קריית אריה יקבל ריבועים קטנים, ושדות ריקים יעלו בקשה אחת. זה מקיף ובאותו זמן חוסך כסף.

## התקנה

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # ומלאי מפתחות
python app.py
```
פתחי `http://127.0.0.1:5000`

## מפתחות שצריך

1. **Google Maps** — ב-[Google Cloud Console](https://console.cloud.google.com/) הפעילי **Places API (New)** וצרי API key.
   ⚠️ השדה `websiteUri` (האתר של העסק) מחויב לפי ה-SKU היקר של Text Search (Enterprise). יש מכסה חודשית חינמית,
   אבל חיפוש "מקיף מאוד" על כמה ערים יכול לעבור אותה. לכן יש **תקרת בקשות** בהגדרות, ו**מטמון** של 14 יום — חיפוש חוזר על אותה עיר כמעט חינמי.
   מומלץ להגדיר גם Budget Alert ב-Google Cloud.
2. **Dorking** — ה-API הרשמי של גוגל (Custom Search JSON API) **סגור למשתמשים חדשים ונכבה ב-1.1.2027**, לכן משתמשים בספק צד שלישי:
   - [Serper.dev](https://serper.dev) — תוצאות גוגל אמיתיות, 2,500 שאילתות חינם בהרשמה (ברירת מחדל)
   - [Brave Search API](https://brave.com/search/api/) — אינדקס עצמאי (`SEARCH_PROVIDER=brave`)

אפשר לעבוד גם עם מפתח אחד בלבד (רק מפות או רק Dorking).

## טיפים
- **מילים נרדפות**: הקלדת `SOC` מחפשת גם "אנליסט SOC", "Tier 1", "מוקד סייבר" וכו'. הרשימה ב-`hidden_jobs/matcher.py` — קל להוסיף.
- **קטגוריות לפי תפקיד**: כל משפחת תפקידים (סייבר/SOC, NOC/IT/רשתות, פיתוח/DevOps/QA/Data) ממופה לסוגי המקומות שמעסיקים אותה — `hidden_jobs/role_profiles.py`. הממשק מציג מראש אילו קטגוריות ייסרקו. תפקיד שלא מוכר למערכת נסרק לפי שמו + חיפוש משרדים כללי. אפשר להוסיף קטגוריות בהגדרות מתקדמות.
- **עמודי React/Angular**: חלק מעמודי הקריירה נטענים ב-JavaScript. התקיני `playwright` + `playwright install chromium` והגדירי `USE_PLAYWRIGHT=1`.
- הלשונית **"חברות עם עמוד קריירה"** שווה זהב גם כשאין התאמה כרגע — אלה חברות באזור שמגייסות, ששווה לשלוח להן קו"ח ישירות.
- המערכת מכבדת `robots.txt` ומגבילה קצב לכל אתר (~2 בקשות בשנייה).

## בדיקות
```bash
python -m pytest -q
```

```
app.py                  שרת Flask + API
templates/index.html    ממשק בעברית
hidden_jobs/
  places.py             שלב 1 — Google Places + Quadtree
  dorking.py            Google Dorking דרך Serper/Brave
  careers.py            שלב 2+3 — זיהוי עמוד קריירה וחילוץ משרות
  ats.py                מתאמים למערכות גיוס (Comeet, Greenhouse, Lever...)
  matcher.py            מילים נרדפות + התאמה (SOC ≠ Social)
  role_profiles.py      איזה סוגי מקומות לחפש לכל תפקיד + סינון לפי סוג מקום
  fetcher.py            HTTP מנומס: robots.txt, הגבלת קצב, Playwright אופציונלי
  pipeline.py           מנצח על כל השלבים
  cache.py              מטמון SQLite
```
